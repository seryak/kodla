## Скиллы aif (оригинальный список)

### Мигрированы

| Файл | О чём |
|------|-------|
| `aif-ru.md` | Настройка проекта (entry point) |
| `aif-build-automation-ru.md` | Makefile/Taskfile/Justfile |
| `aif-plan-ru.md` | Планирование реализации |
| `aif-improve-ru.md` | Улучшение плана |
| `aif-explore-ru.md` | Режим исследования |
| `aif-verify-ru.md` | Проверка реализации |
| `aif-implement-ru.md` | Выполнение плана |
| `aif-evolve-ru.md` | Самообучение AI Factory |
| `aif-fix-ru.md` | Исправление багов |
| `aif-docs-ru.md` | Документация проекта |
| `aif-rules-ru.md` | Правила и конвенции |
| `aif-ci-ru.md` | CI/CD пайплайны |
| `aif-commit-ru.md` | Conventional Commits |
| `aif-reference-ru.md` | База знаний (references) |

### Планируются к миграции

| Файл | О чём |
|------|-------|
| `aif-rules-check-ru.md` | Проверка соблюдения правил |

| `aif-dockerize-ru.md` | Docker-конфигурация |
| `aif-review-ru.md` | Code Review |

| `aif-architecture-ru.md` | Архитектурные паттерны |
